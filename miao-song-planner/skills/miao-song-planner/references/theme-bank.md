## 自定义主题锚定规则

1. 用户已给出主题或一句话概念时，直接进入第 2 轮，不展示主题菜单。
2. 把用户主题提炼为「谁 + 何时何地 + 什么情绪」三要素；例如「晚上十点地铁里想一个人」→ 深夜都市分支，「毕业前最后一次操场夜跑」→ 逆风成长分支。
3. 三要素无法对应既有主题时，以情绪为主导继续：偏忧郁/孤独 → Dark R&B 或 Quiet Storm；偏浪漫/温暖 → Neo-Soul；偏自信/律动 → Funk-R&B。
4. 后续轮次始终优先使用自定义主题的原话定义情绪与歌词意象；映射只用于选择曲风分支，不改变用户主题。

## 主题命名与锚定建议

- 用「具体意象 + 情绪」命名主题，避免抽象词（「遗憾」→「没发出去的消息」）。
- 确认一句话概念时包含：时间（深夜/清晨/夏天）、地点（地铁/海边/出租屋）、情绪词（孤独/心动/释怀），方便后续歌词与编曲统一。
