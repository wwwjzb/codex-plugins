## 二、通用规则（所有风格适用）

- 本库的通用规则与各风格数据面向**妙响（Sway5.5）最终风格框**；生成 **MiniMax 试听/成品 prompt** 时，按 `references/minimax-caption.md` 的官方词库与三段式写法组装（允许 808 sub-bass、rolling triplet hi-hats、Clap 等），不受本库高频禁用表限制。
- 高频安全替代：细分节奏由闷音吉他十六分、短 Rhodes Stab、木质 Rim、低 Tom、低 Conga、短人声辅音承担。
- 通用禁用：开镲（Open Hat）、吊镲（Crash/Ride/Cymbal）、Shaker、Tambourine、白噪声、嘶声、静电、失真铺底、黑胶/磁带/Lo-fi 纹理词；细分节奏默认用安全替代。
- 风格例外（唯一）：**Trap-Soul 允许受控闭镲 16 分连击与 Clap**——这是 trap 身份必需，但 prompt 必须写「受控、不刺耳、音量压低」；其余 14 个风格一律不用镲片与 Clap。
- 鼓组筛选规则：第 6 轮律动选项**只从所选风格自己的「律动方案」出**，跨风格鼓型（trap 808、2-step、funk 十六分、Disco 脉冲等）不得混入不匹配的风格；除非某风格明确把该鼓型列为「变体」，且选中后 prompt 逐拍写清。
- 明亮度：人声清晰靠前、低中频（200-500 Hz）不堆积、混响短而受控；「明亮」不靠提升高频或加镲片。
- 男低声（E2-C4 舒适区）：主歌 3-5 度邻近运动；副歌最高音短暂停留，靠长音下的和声变化制造豪华感；转音优先下方滑入、三音回转、九/六音延迟解决；四句 Hook 只在第 2、4 句放转音。
- 女声：温暖醇厚女中音舒适音域 G3-D5，最高不超过 E5；主歌低音区近场演唱，副歌厚实混声 + 叠唱；避免尖亮女高音与持续高音。
- 特殊拍号（如 6/8）必须写明「每小节音符数量 + 重拍位置 + 律动感」，否则模型容易生成普通四拍。
- 纯音乐：歌词框写「纯音乐」，风格描述不出现任何主唱、唱法、和声人声描述。

## 三、各风格分支数据

### 1. 2000s Contemporary / Pop-R&B

- **适配主题**：逆风成长、清晨告白、夏日恋曲
- **情绪池**：自信张扬 / 怀旧温暖 / 心动甜蜜 / 坚定有力 / 洒脱释怀 / 恋恋不舍
- **人声池**：
  1. 女中音：温暖醇厚，G3-D5，副歌混声 + 叠唱
  2. 男中音：年轻温暖略带气声，主歌口语短句，副歌低八度叠唱
  3. 女高音：清亮通透，最高 E5，避免持续高音
  4. 男高音：明亮有辨识度，气声主导、细腻转音
  5. 中性烟嗓：中低音区略带沙哑，句尾滑音
  禁用：连续高音、夸张炫技、嘶吼
- **编配组合**：
  1. 钢琴 + 合成贝斯 + 弦乐群
  2. Rhodes + 电贝斯 + 轻鼓
  3. 尼龙弦吉他 + 弦乐 + 温暖贝斯
  4. 洁净电吉他 + 氛围合成器 + 电贝斯
  5. 钢琴 + 808 + 稀疏 Pad
- **律动方案**：
  1. 清晰 4/4 切分：Kick 在 1、3 拍，闷 Snare 在 2、4 拍半，贝斯切分回答
  2. 慢拍鼓后置：鼓整体后移半拍，贝斯先行
  3. 半速 Trap 变体（如选此项，必须按 Trap-Soul 显式鼓组写法：Kick 1 拍 / Snare 3 拍 / 闭镲 16 分，写明「非 Boom Bap」）
  4. 2-step 跳拍：跳拍 Kick + 闷 Rim 细分
  5. Funk 十六分：闷音吉他十六分 + 短 Rhodes Stab 维持细分
- **BPM/拍号**：
  1. 84 BPM 4/4，重拍 1、3
  2. 92 BPM 4/4，重拍 2、4
  3. 76 BPM 4/4，鼓后置
  4. 70 BPM 6/8，每小节 6 个八分音符、重拍 1、4，向前滚动，不要做成普通四拍
  5. 100 BPM 4/4，十六分切分律动
- **适配结构**：流行结构、嘻哈结构
- **段落发展**：主歌克制口语化 → 预副歌只抬升和声密度 → 副歌完整鼓组 + 叠唱 → Bridge 抽掉鼓组 → Final Chorus 加低音通鼓过门 → Outro 渐弱

### 2. Traditional / Adult R&B / Quiet Storm

- **适配主题**：破碎告别、旧日重逢、深夜都市
- **情绪池**：忧郁伤感 / 温柔眷恋 / 深夜亲密 / 克制隐忍 / 怀旧百感 / 慵懒放松
- **人声池**：
  1. 男低音：E2-C4 舒适区，胸声叙事，句尾细腻装饰
  2. 女中音：温暖醇厚 G3-D5，低音区亲密演唱
  3. 男中音：丝滑气声，长线条、呼吸自然
  4. 女高音：柔和清亮，长音有光泽，最高 E5
  5. 中性偏烟嗓：近场私语感，句尾下滑
  禁用：高亢嘶吼、持续高音、密集转音
- **编配组合**：
  1. Rhodes + 钢琴 + 温暖贝斯 + 弦乐
  2. 钢琴 + 大提琴 + 贝斯
  3. 暗 Pad + Sub + 混响吉他
  4. 电钢琴 + 尼龙吉他 + 轻弦乐
  5. 单一键盘 + 近场人声（极简）
- **律动方案**：
  1. 慢拍鼓后置：Kick 后移、闷 Snare 轻触，鼓声稀疏
  2. 无鼓：纯和弦 + 贝斯 + 人声
  3. 极简脉冲：心跳感低音鼓，无细分打击
  4. 轻柔切分：Kick 1 拍 + 闷 Rim 轻点 3 拍，节拍整体后移
  5. 慢速摇摆：Kick 稀疏 1 拍 + 闷 Rim 3 拍轻触，贝斯走低音长音
- **BPM/拍号**：
  1. 72 BPM 4/4，鼓后置
  2. 68 BPM 4/4，慢速
  3. 64 BPM 6/8，重拍 1、4，摇摆滚动
  4. 78 BPM 4/4，轻切分
  5. 60 BPM 4/4，极慢
- **适配结构**：流行结构、极简循环
- **段落发展**：主歌低区叙事 → 副歌不升高，靠和声层变厚与低八度叠唱 → Bridge 换和弦色彩 → Outro 乐器淡出

### 3. Neo-Soul / Organic Soul

- **适配主题**：夏日恋曲、清晨告白、旧日重逢
- **情绪池**：慵懒甜蜜 / 温暖治愈 / 浪漫松弛 / 俏皮灵动 / 怀旧 / 自然随性
- **人声池**：
  1. 女中音：胸声松弛、句尾俏皮转音
  2. 男中音：拍后演唱、蓝调滑音
  3. 男高音：丝滑上滑、稳定中音 Hook
  4. 女声气声：轻柔、咬字个性化
  5. 沙哑女声：温暖粗糙质感
  禁用：机械化节奏、僵硬咬字、持续炫技
- **编配组合**：
  1. Rhodes + 现场贝斯 + 轻鼓
  2. 木吉他 + 键盘 + 轻打击
  3. Funk 吉他 + 铜管短句
  4. Wurlitzer + 贝斯 + 弦乐
  5. 单键盘 + 近场人声
- **律动方案**：
  1. 人性化微时差 Pocket：辅音稍后放，慵懒后置
  2. 松拍鼓 + 贝斯循环
  3. 拍后演唱 + 吉他句尾回答
  4. 稀疏低音鼓 + 闷 Rim 细分
  5. Bass-led 切分：贝斯在 Kick 后回答
- **BPM/拍号**：
  1. 82 BPM 4/4，深 Pocket
  2. 74 BPM 4/4，松拍
  3. 90 BPM 4/4，十六分切分
  4. 70 BPM 6/8，重拍 1、4，摇摆
  5. 96 BPM 4/4，Funk Pocket
- **适配结构**：流行结构、嘻哈结构
- **段落发展**：主歌辅音后置制造慵懒 → 副歌每四句改变一次咬字密度 → Bridge 和声扩展 → Outro 乐器句尾互答

### 4. Alternative / Progressive R&B

- **适配主题**：深夜都市、异乡漂泊、破碎告别
- **情绪池**：迷离疏离 / 克制内省 / 悬而未决 / 冷感暧昧 / 实验好奇 / 孤独清醒
- **人声池**：
  1. 男中音：平静叙事、略偏离预期的落点
  2. 女中音：轻声层叠、非传统句法
  3. 男低音：低音主歌 + 背景和声上移，主唱保持中低区
  4. 女高音：轻声高音反差、气声
  5. 中性声线：半说半唱、不规则短句
  禁用：效果器铺满全曲、模糊到听不清咬字
- **编配组合**：
  1. 模糊合成器 + 变形采样
  2. 另类吉他 + Sub
  3. 冷色键盘 + 稀疏电子鼓
  4. 复杂贝斯 + Jazz 和声 + 轻鼓
  5. 弦乐 + 温暖键盘 + 轻盈节奏
- **律动方案**：
  1. 不规则密度 + 负空间（句长不对称，每 4 小节保留明确落点）
  2. 稀疏鼓 + 空间效果
  3. 断裂电子鼓（低音量、短时值）
  4. 2-step 跳拍 + 闷 Rim
  5. 极简低频脉冲
- **BPM/拍号**：
  1. 72 BPM 4/4，不规则重音
  2. 66 BPM 4/4，慢速
  3. 88 BPM 4/4，负空间
  4. 60 BPM 4/4，极简
  5. 96 BPM 4/4，切分
- **适配结构**：极简循环、电子结构、流行结构
- **段落发展**：主歌保持单调中心让歌词节奏制造变化 → 副歌用短 Hook 做锚点 → Bridge 换音色与和声视角 → Outro 滤波/反向混响收尾（仅转场、低音量）

### 5. Trap-Soul / Hip-hop R&B

- **适配主题**：破碎告别、夜色舞池、逆风成长
- **情绪池**：暗恋压抑 / 自信张扬 / 心碎麻木 / 挑逗戏谑 / 倔强反击 / 夜晚孤独
- **人声池**：
  1. 男低音：旋律说唱、低音区、短句
  2. 女中音：轻声短句、重复但不僵硬
  3. 男中音：低音旋律说唱 + 短 Hook
  4. 女声烟嗓：自信咬字、辅音当打击乐
  5. 男高音：副歌短高音落点、不持续
  禁用：连续高音、纯 Rap 无音高落点、嘶吼
- **编配组合**：
  1. 808 + 稀疏键盘
  2. 吉他/键盘循环 + 克制的 Trap 鼓
  3. 暗 Pad + 808 + 短 Pluck
  4. 钢琴 + 808 + 人声和声层
  5. 合成贝斯 + 冷色纹理 + 负空间
- **律动方案（全部保持 trap 身份：808 sub-bass + rolling hi-hats + snare/clap，非采样 Boom Bap 循环）**：
  1. 经典 trap：punchy 808 kick + crisp snapping snare/clap + rapid rolling triplet hi-hats（140–150 BPM 半速听感）
  2. 标准 140：kick + snare/clap + 16 分闭镲连击（全速 140，半速听感 70）
  3. 808 滑音 trap：sliding 808 sub-bass + snare/clap + 复杂切分 hi-hat
  4. 留白 trap：只留 kick + snare/clap，镲只在句尾滚奏
  5. 慢速 trap：65–72 BPM，kick + 轻 snare/clap + 极简 hat
- **Trap 鼓组显式写法（2026-08-14 官方核对，写进 prompt）**：官方模板原文是 "classic trap foundation featuring a punchy kick drum and a crisp, snapping snare/clap on beats 2 and 4. Rapid, rolling hi-hat patterns with frequent triplet subdivisions and pitch variations"；与 Boom Bap 的区分靠「rolling triplet hi-hats + 808 sub-bass 保持突出」而不是军鼓位置，并补一句 "keep the rolling hi-hats and 808 sub-bass prominent; not a sampled boom-bap loop"。不要用「闷 Snare、闷 Rim」等妙响式替代词写 MiniMax prompt。
- **BPM/拍号**：
  1. 140 BPM 4/4（半速听感 70）
  2. 150 BPM 4/4（半速听感 75）
  3. 72 BPM 4/4
  4. 65 BPM 4/4
  5. 160 BPM 4/4（半速听感 80）
- **适配结构**：嘻哈结构、极简循环
- **段落发展**：Verse 用密度变化 → Chorus 音符时值变长 → 句尾留一拍给乐器或 Delay 回答 → Bridge 减字、放慢滑入长音

### 6. Dark / Atmospheric R&B

- **适配主题**：深夜都市、破碎告别、异乡漂泊
- **情绪池**：阴郁压抑 / 脆弱孤独 / 危险暧昧 / 悬疑克制 / 麻木疏离 / 深夜自省
- **人声池**：
  1. 男低音：低声叙事、副歌中音长音
  2. 男中音：脆弱音色 + 对比强烈长音
  3. 女中音：轻声层叠、克制 Hook
  4. 女高音：气声长音、不尖锐
  5. 中性声线：半说半唱、留白多
  禁用：高亢吼唱、密集转音、主唱被闷住
- **编配组合**：
  1. 暗 Pad + Sub + 混响吉他
  2. 钢琴 + 大提琴 + 深贝斯
  3. 断裂电子鼓 + 低频细节
  4. 另类吉他 + Sub + 空间效果
  5. 极简键盘 + 近场人声
- **律动方案**：
  1. 极简低频脉冲：心跳感低音鼓
  2. 慢速鼓后置
  3. 断裂鼓（低音量、短时值）
  4. 留白为主的稀疏鼓
  5. 2-step 跳拍 + Sub
- **BPM/拍号**：
  1. 68 BPM 4/4，慢速脉冲
  2. 60 BPM 4/4
  3. 58 BPM 4/4，极慢
  4. 72 BPM 4/4，负空间
  5. 55 BPM 4/4
- **适配结构**：极简循环、流行结构
- **段落发展**：Intro 留空 → 主歌低声叙事 → 首次副歌不完全释放 → 逐段扩张音域与低频厚度 → Outro 悬而未决

### 7. Electronic / Future R&B

- **适配主题**：深夜都市、夜色舞池
- **情绪池**：未来迷幻 / 轻盈兴奋 / 冷感疏离 / 律动快感 / 梦境游离 / 克制科技感
- **人声池**：
  1. 女中音：轻声短 Hook 落在 Groove 内部
  2. 男中音：口语化旋律、逐渐开放
  3. 男低音：高 Hook 下移八度、保留节奏轮廓
  4. 女声气声：音色化人声、短句
  5. 中性声线：跳进断句、音节化咬字

### 结构 → 段落发展模板（第 12 轮至少展示 5 条）

1. 克制渐入型：Intro 留空 → 主歌稀疏 → 副歌完整 → Bridge 抽空 → Final Chorus 爆发
2. 分层叠加型：每段加一层和声或乐器，从单薄到饱满
3. 对比反差型：主歌私语 → 副歌全配器；Bridge 换调或换唱法
4. 回声呼应型：每句句尾留白给乐器回答；Hook 三次重复每次加回应
5. 首尾呼应型：Outro 回扣 Intro 动机、乐器渐弱
6. 渐进加密型：BPM 不变，音符密度逐段增加

各结构的段落序列：

- 流行结构：Intro → Verse 1 → Pre-Chorus → Chorus → Interlude → Verse 2 → Pre-Chorus → Chorus → Bridge → Final Chorus → Outro
- 嘻哈结构：Intro → Verse 1 → Pre-Chorus → Chorus/Hook → Verse 2 → Pre-Chorus → Chorus/Hook → Bridge → Chorus/Hook → Outro
- 电子结构：Intro → Build-Up → Drop/Climax → Breakdown → Build-Up → Drop → Outro
- 极简循环：短循环 2-4 小节建立记忆点，副歌通过和声与乐器层升级而非改写旋律
- 纯音乐：段落序列同上，但歌词框写「纯音乐」，全曲无人声
