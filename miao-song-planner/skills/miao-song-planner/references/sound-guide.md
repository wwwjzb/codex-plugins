# 声音指南（问卷第 7/8/11 轮 + 风格描述撰写）

> 本指南是**妙响（Sway5.5）最终风格框**的规则（高频噪声排除、安全替代、明亮度、效果器）；生成 **MiniMax 试听/成品 prompt** 时**不使用**本指南的高频禁用词表与替代词，改用 `references/minimax-caption.md` 的官方词库（808、triplet hi-hats、Clap 等直接可用）。

## 一、高频噪声排除（Sway5.5）

### 现象与原因

- 鼓组进入后出现持续「滋滋/嘶嘶」噪声，加入人声后高潮更吵；仅人声或钢琴时通常干净。
- 主因：Hi-Hat、Ride、Crash、Shaker、Tambourine、Clap 等高频打击过度叠加；快速循环 Hi-Hat 与密集 Shaker 易产生高频失真与削波。
- 「雨声、黑胶、磁带、Lo-fi、环境氛围、失真电吉他」等宽频词会恶化问题。

### 方案 A：彻底禁止高频打击层（推荐）

- 鼓组只用圆润低音鼓、闷音军鼓、低音通鼓。
- 完全不要 Hi-Hat、Open Hat、Crash、Ride、Cymbal、Shaker、Tambourine、Clap。
- 不要滋滋声、嘶嘶声、白噪声、静电、削波、失真、过度压缩。
- 高潮只增加低音鼓、弦乐和贝斯厚度，不增加高频。

### 方案 B：正向约束（需要一点细分节奏时）

- 只使用非常轻的封闭 Hi-Hat、稀疏节奏；不出现 Crash、Ride、开放镲、快速镲片循环。
- 鼓组高频减少、暗调温和；只在段落转换处加入极轻镲片。

### 方案 C：删词

- 删除噪声类（噪声/嘶声）、纹理类（黑胶/磁带/Lo-fi）、效果类（失真/饱和）、环境类（雨声/空气感）词汇。

### 高危词汇清单

```text
Hi-Hat、Crash、Ride、Shaker、Tambourine、Open Hat、现场鼓组、失真电吉他、Lo-fi、黑胶、噪声、空气感、环境氛围、磁带饱和、白噪声、静电
```

### 排查步骤

1. 纯器乐测试是否仍有噪声。
2. 删除军鼓，只留低音鼓。
3. 换曲风为「悲伤钢琴叙事」。
4. 降低 BPM 10-15。

## 二、高频安全替代表（按风格，保留律动不掉细分）

| 原风格元素 | 安全替代 | 适用风格 |
| --- | --- | --- |
| Hat/Shaker 十六分 | 闷音吉他十六分、短 Rhodes Stab、木质 Rim、低 Tom | Funk、Disco |
| 密集 Hat | 木质 Tick、闷 Rim、短和弦 Stab | UK R&B、Garage |
| Shaker/高频打击 | 软木 Block、低音 Conga、闷 Rim、短吉他拨弦、人声辅音 | Afro-R&B |
| 开放镲/Crash | 不替代，直接去掉；用低音 Tom 过门做段落信号 | 全部 |
| Clap | 短人声辅音、闷 Rim；Trap-Soul 例外：允许受控 Clap（非刺耳、音量压低） | Trap-Soul |

规则：Funk、Garage、Afro 等风格不能把细分节奏全部删除，否则风格退化；用上述替代保住律动。**Trap-Soul 例外**：闭镲 16 分连击与 Clap 是风格身份必需，允许使用但必须受控（音量压低、不刺耳），不可替换成闷 Rim 后丢失 trap 特征；Kick 落 1 拍、Snare/Clap 落 3 拍，禁止 2/4 拍反拍（非 Boom Bap）。

## 三、明亮度要求（「明亮」= 音色与混音清晰度）

### 定义

- 主唱清晰、通透、靠前，咬字容易听清；人声有光泽和适度空气感，但不尖锐、不刺耳。
- 人声不被贝斯、键盘、吉他或混响遮盖；低中频不堆积，整体不闷不糊。
- 鼓、贝斯、主旋律各有位置；高潮有力度但不过度拥挤。

### 不要误解为

- 不代表提高 BPM、必须用大调、提高歌曲音高或持续唱高音。
- 不代表提升高频、加入密集镲片或提高整体响度；过度提升高频会造成齿音和刺耳感。
- 不代表很宽很长的混响；过量混响把人声推远、伴奏变糊。

### 可落地的混音要求

- 主唱近距离录音感、声场中央靠前；辅音完整；短而受控的混响。
- 低频紧实稳定；减少 200-500 Hz 浑浊堆积；键盘/吉他/合成器给主唱留中频空间。
- 副歌增强来自低音鼓、贝斯、和声与编配层次；立体声自然展开但主唱与低频稳定居中。
- 避免过度压缩、过度限制和响度竞争；保留鼓点与主唱的动态冲击。

## 四、效果器安全做法（第 11 轮选项池）

| 场景 | 做法 | Sway5.5 安全注意 |
| --- | --- | --- |
| 开头首句 | 轻电话滤波，仅首词或 1-2 秒 | 持续滤波令男低声变薄 |
| 主歌 | 短 Plate/Room，近场主唱居中 | 长混响遮盖辅音 |
| 关键词 | Slapback / Delay Throw，只抛最后 1-2 个词 | 每句使用会混乱 |
| 预副歌入口 | 极短 Reverse Reverb 吸入 | 宽频尾巴会变成嘶声 |
| 副歌 | 低八度 Double + 三层和声，主唱居中、和声向两侧展开 | 过宽和声冲淡主唱 |
| Bridge | Reverb Automation：由近到远，副歌前收干 | 长尾遮住副歌第一拍 |
| Dark/Alternative 转场 | 滤波、颗粒、变调只用于过门或背景 | 全曲处理会模糊成噪声 |

第 11 轮至少展示 5 个方案，且每个方案都要注明上面的安全注意。Vocal Chop 只允许低音量、短时值；侧链感用「音量包络」描述，不写「重度泵动压缩」。

### 干净模板（带人声）

```text
一首[情绪和主题]的现代华语 R&B。速度为 [BPM] BPM，[调性]。[拍号和重拍说明]，不要做成普通四拍流行歌。
整体编曲[简洁/饱满]，保留适量空白。使用[键盘乐器]、[贝斯类型]、[吉他/其他乐器]和[合成器类型]，贝斯、鼓与和弦之间[互动方式]。
鼓组随段落变化：主歌[鼓型]；预副歌[鼓型]；副歌[鼓型]；桥段[鼓型]；末段[鼓型或过门]。不要从头到尾重复同一套鼓点。
[人声类型]近距离演唱，音色[音色特征]。主歌使用[主歌唱法]；副歌使用[副歌唱法]。不要[禁用音域或唱法]。
整体声音[混音要求]，情绪从[起始情绪]逐渐走向[结束情绪]。
不要密集镲片、快速高频鼓点、开放镲、Crash、Ride、Shaker、Tambourine、持续环境噪声、失真或过度压缩。
```

### 干净模板（纯器乐）

```text
[BPM] BPM [调性] 伤感电影配乐，干净无噪。鼓组只使用圆润低音鼓、闷音军鼓。不要 Hi-Hat、Crash、Ride、Cymbal、Shaker、Tambourine、Clap。不要滋滋声、白噪声。[核心乐器]。无主唱无人声。
```

### 明亮度专用段（按需并入风格描述）

```text
人声清晰、明亮、通透且明显靠前，采用近距离演唱和清楚咬字，保持自然光泽与适度空气感。人声不能发闷、不能被伴奏遮盖，也不要出现尖锐齿音或刺耳高频。伴奏层次清楚，低频紧实，低中频不堆积，键盘、吉他和合成器为主唱留出足够空间。鼓组有弹性和冲击力，但不过度压缩；混响短而受控，整体混音干净、自然、清晰。这里的「明亮」只指人声音色与混音清晰度，不要求提高 BPM、不要求使用大调、不要求提高歌曲音高，也不要求增加密集高频打击乐。
```
