# 最终方案组装模板

问卷 8 轮结束后，按下面 6 个部分一次性输出。以下为结构与填写规范，不是填空模板——内容必须来自问卷答案并整合参考库。

> 标签注意：歌词框中的 [Final Chorus] / [Pre-Chorus] / [Post-Chorus] 是妙响/方案展示写法；**提交给 MiniMax 生成时**，末段副歌一律改用 [Chorus]，并用 `[Chorus][full arrangement, layered vocals, ad-libs, emotional peak]` 表达升级（官方 14 个标签无 [Final Chorus]）。

## 1. 歌名

- 给 2-3 个候选，每个一句话说明来源（主题意象 / Hook 短语 / 情绪）。
- 推荐 1 个：优先选择由副歌 Hook 提炼、可唱、可记忆的短语；避免生僻字与多音字。

```text
候选：
《A》—— 来自主题意象「...」
《B》—— 来自 Hook 短语「...」
推荐：《A》
```

## 2. 歌词框（可直接粘贴到妙响）

- 使用英文段落标签 + 英文分段指令；段落间空行；每段 4-8 行；即兴/旁白用圆括号。
- Hook 完整重复 2-3 次；重复时靠和声/乐器层升级。
- 交付前逐行检查多音字：优先改写整句 → 换词 → 最后才同音字；含风险字时在蓝图中列出处理说明。
- 纯音乐作品：歌词框只写 `纯音乐`，风格描述不出现人声。

```text
[Intro][warm Rhodes chords, distant city ambience, breathy humming]

[Verse 1][sparse drums, close-mic vocal, restrained delivery]
第一段歌词
第二段歌词
第三段歌词
第四段歌词

[Pre-Chorus][sub bass rises, tension builds]
...

[Chorus][full groove enters, layered harmonies, wider stereo field]
副歌 Hook
...

[Bridge][drums strip back, minimal piano]
...

[Final Chorus][full arrangement, layered vocals, ad-libs, emotional peak]
...

[Outro][drums fade out, whispered vocal]
...
```

## 3. 风格描述框（可直接粘贴到妙响）

按顺序组织：曲风/速度 → 调性/情绪 → 人声 → 乐器与律动 → 段落发展 → 混音空间 → Sway5.5 禁用清单。参考 sound-guide.md 的模板；需要「明亮」时并入明亮度专用段。

```text
一首[情绪和主题]的[核心曲风]。速度为 [BPM] BPM，[调性]。[拍号和重拍说明]，不要做成普通四拍流行歌。
整体编曲[简洁/饱满]，保留适量空白。使用[核心乐器组合]，[贝斯、鼓与和弦互动方式]。
鼓组随段落变化：主歌[鼓型]；预副歌[鼓型]；副歌[鼓型]；桥段[鼓型]；末段[鼓型或过门]。不要从头到尾重复同一套鼓点。
[人声类型]近距离演唱，音色[特征]。主歌[唱法]；副歌[唱法]。不要[禁用项]。
整体声音[混音要求]，情绪从[起始]走向[结束]。
不要密集镲片、快速高频鼓点、开放镲、Crash、Ride、Shaker、Tambourine、持续环境噪声、失真或过度压缩。
```

## 4. 参数建议

每项给一个数值并附一句理由。以下为经验起始值，标注「建议」而非官方固定值。

| 创作目标 | 风格权重 | 参考音频权重 | 创意发散 |
| --- | ---: | ---: | ---: |
| 只换人声，尽量保留原曲 | 4-6 | 9-10 | 2-4 |
| 保留旋律并转换曲风 | 7-9 | 6-8 | 4-6 |
| 明显仿写与重新编配 | 7-9 | 3-5 | 7-9 |
| 无参考音频的原创方向 | 7-9 | 不适用 | 5-7 |
| 噪声问题复现时 | 8-9 | 2-5 | 2-4 |

```text
人声性别：男声/女声（依据第 5 轮选择）
风格权重：
参考音频权重：（无参考音频时注明「不适用」）
创意发散程度：
理由：...
```

## 5. 创作蓝图

### 5.1 基础参数

- BPM / 拍号：来自第 10 轮；特殊拍号写明重拍位置。
- 调性：给一个建议调（如升 C 小调），与情绪匹配；小调同样可以明亮。
- 预计小节数 / 预计时长：按结构列出每段小节数；4/4 拍每小节约 `60 ÷ BPM × 4` 秒，汇总总时长。

### 5.2 旋律轮廓（五选一）

| 轮廓 | 结构 | 适合情绪 |
| --- | --- | --- |
| 问答型 | 短上行提问 → 下行回答 | 暧昧、期待 |
| 拱形 | 中音进入 → 小幅抬升 → 回落 | 浪漫、完整 |
| 悬停型 | 围绕 2-3 个音 → 末尾才解决 | 克制、迷离 |
| 节奏 Riff 型 | 少量音高 + 强节奏重复 | 自信、性感 |
| 阶梯增长型 | 每四小节提高音值或音区 | 逐渐释放 |

### 5.3 副歌四句模板与 Flow 蓝图

```text
第 1 句：标题/问题，短上行，末尾留白
第 2 句：旋律展开到最高舒适音，句尾三音回转（男低声只在第 2、4 句放转音）
第 3 句：下行回应，背景和声打开
第 4 句：回到稳定主音，最后一个词做一次 Delay Throw
```

旋律说唱 Flow（Trap-Soul/Dancehall 等）：

```text
第 1 句：2-3 个短音 + 休止 + 一个长音落点
第 2 句：增加一个拍前音，句尾仍留空
第 3 句：字数密度最高，连续快速音不超过半小节
第 4 句：减字、放慢，滑入稳定音
每句保留至少一个可辨认音高；每四句更换重音形状；结构落点必须清楚。
```

### 5.4 和声方向

- 给出 1-2 句和声特征：如「min9 Rhodes 悬停制造想说未说的张力」「主歌窄音域、副歌和声上移」「Bridge 用替代和弦改变色彩」。
- 低音区主唱时，背景和声上移、主唱保持中低区。

### 5.5 前三秒抓耳入口（六选一）

| 类型 | 0-3 秒安排 |
| --- | --- |
| 人声直入 | 3-5 音标题 Hook，随后乐器回答 |
| 器乐 Riff | 吉他/Rhodes/贝斯短动机 |
| 节奏签名 | 单个重音或特殊 Snare/2-step 缺口 |
| 和声悬念 | 一枚未解决的 maj7/min9/无根和弦 |
| 音色变形 | 短促 Vocal Chop/滤波词尾（低音量） |
| 对话式开场 | 低声一句 + 背景短回答 |

前三秒只突出一个身份；完整鼓组、Pad、多层和声稍后进入。

### 5.6 副歌三次回归矩阵

| 回归次数 | 鼓/低频 | 和声 | 人声 | 效果器 |
| --- | --- | --- | --- | --- |
| 第一次 | 完整基础 Pocket | 一层低/中和声 | 主唱清楚、少量 Double | 末词一次短 Delay |
| 第二次 | Bass 多一个回答、Kick 稍厚 | 加三度或六度层 | 低八度 Double | 声场略宽，不加长混响 |
| 最终 | 低音 Tom 过门或动态提升 | 三层和声 + 短 Call-and-response | 主旋律不变，1-2 句 Ad-lib | 结尾 Delay/Plate 自动化 |

## 6. 试听检查清单（附在方案末尾）

- [ ] 每轮选择已完整汇总（主题/曲风/情绪/歌词风格/人声/编配/律动/制作/结构/BPM/效果器/段落发展）
- [ ] 歌词多音字已逐行检查，风险字处理有说明
- [ ] 风格描述无高频噪声禁用词、无艺人姓名、无主观空话
- [ ] 参数建议有理由，且标注为经验建议
- [ ] 蓝图包含 BPM/拍号/时长、旋律轮廓、Flow、和声、前三秒入口、回归矩阵
- [ ] 生成后按 sound-guide.md 的试听清单核对明亮度与噪声
