# 歌词指南（问卷第 4/9/12 轮 + 歌词撰写）

## 一、歌词格式规则（妙响）

- 段落名称使用英文，并用方括号元标签标记：`[Verse 1]`、`[Pre-Chorus]`、`[Chorus]`、`[Bridge]`、`[Final Chorus]`、`[Outro]`。
- 段落标签后紧跟一个英文分段指令（描述该段编曲、唱法、情绪），同样用方括号，位于歌词正上方：

```text
[Chorus][full R&B groove enters, layered vocals, emotional lift]
第一行歌词
第二行歌词
第三行歌词
第四行歌词
```

- 每段歌词 4-8 行效果最好（不是硬性限制）；不同段落之间空一行。
- 即兴、和声回应、旁白使用圆括号：`(别再让我等太晚)`。
- 纯音乐作品在歌词框输入 `纯音乐` 或 `Instrumental`。
- 全文元标签大小写保持一致。

## 二、歌词风格/叙事方式（第 4 轮选项池，≥6 项）

1. **意象铺陈**：用画面与物象推动情绪（雨、窗、灯、旧车票），少用直白情绪词；适合深夜都市、异乡漂泊。
2. **故事推进**：有明确时间线（开始-转折-结果），每段推进一个情节；适合破碎告别、逆风成长。
3. **对话体**：直接对「你」说话，口语化短句，像深夜通话；适合破碎告别、清晨告白。
4. **独白体**：内心独白、反问、留白，句子可以断在未完成处；适合深夜都市、旧日重逢。
5. **旋律说唱 Flow**：四句一组密度变化（短短长+留白 → 提前音 → 高密度 → 减字滑入长音），每句保留一个音高落点；适合 Trap-Soul、夜色舞池。
6. **留白短句**：每段 4 行左右短句，大量呼吸感，Hook 是重复的短句；适合 Bedroom、Alternative。
7. **信件/旁白体**：以「写给你的信」或画外旁白结构推进，段落间用括号插入环境声提示；适合异乡漂泊、旧日重逢。
8. **纯音乐（无歌词）**：歌词框写 `纯音乐`，第 5 轮人声不适用，风格描述不出现任何主唱/唱法/和声人声描述；适合场景音乐与配乐化 R&B。

规则：第 4 轮按情绪从上述池中选出 ≥5 项展示；其余选项由助手按主题补足并附一句话说明。

## 三、段落功能与分段指令示例

| 段落 | 功能 | 指令写法示例 |
| --- | --- | --- |
| Intro | 建立基调，少歌词或无人声 | `[Intro][warm Rhodes chords, distant rain ambience, breathy humming]` |
| Verse 1 | 推进故事，克制 | `[Verse 1][sparse electronic drums, close-mic vocal, restrained delivery]` |
| Pre-Chorus | 积蓄张力 | `[Pre-Chorus][sub bass rises, soft finger snaps, emotional tension builds]` |
| Chorus | 核心 Hook，配器丰富 | `[Chorus][full groove enters, layered harmonies, wider stereo field]` |
| Bridge | 抽空对比 | `[Bridge][drums strip back, minimal piano, intimate falsetto]` |
| Final Chorus | 情绪高潮 | `[Final Chorus][full arrangement, layered vocals, ad-libs, emotional peak]` |
| Outro | 收束淡出 | `[Outro][drums fade out, whispered vocal, rain ambience disappears]` |

发展逻辑：Intro/Verse 稀疏简单 → Pre-Chorus 增加节奏或和声张力 → Chorus 配器更丰富、声场更宽 → Verse 2 保留统一性并加少量新元素 → Bridge 抽掉鼓组或切换唱法 → Final Chorus 完整配器与叠唱 → Outro 写明收尾方式。

## 四、韵脚与 Hook 原则

- 一首歌核心韵部控制在 1-2 个，避免为押韵牺牲语义。
- 开口呼韵（a/ang/ao/an）开阔，适合大气激昂；闭口呼韵（i/in/ing/ü）细腻，适合温柔伤感；短促韵（e/o/uo）轻快，适合俏皮或强节奏。
- 可按段落情绪换韵：主歌内敛，副歌转更开阔的韵脚。
- 使用统一隐喻或象征系统，让意象贯穿全曲；用具体细节叙事呈现矛盾。
- Hook 用简单短句，完整重复 2-3 次；重复时通过和声、乐器层和动态升级，而不是改写核心旋律与歌词。

## 五、多音字避错规则

### 处理顺序

1. **优先改写整句**：换成含义相同、只有一个常用读音的表达。
2. **其次替换词语**：用同义词避开多音字，保持字数、节奏、韵脚接近。
3. **最后使用同音字**：仅在无法自然改写时使用；交付前必须试听，并另存一份语义正确的正式版歌词。

### 常见风险字改写示例

| 原句 | 风险 | 推荐改写 |
| --- | --- | --- |
| 还你一个夏天 | 「还」可能读成 hái | 送你一个夏天 |
| 还在我的身边 | 「还」可能读成 huán | 依然在我身边 |
| 把喜欢藏在心里面 | 「藏」可能误读 | 把喜欢留在心里面 |
| 影子被夕阳拉得很长 | 「长」可能误读 | 夕阳把影子拉向远方 |
| 我们以后还会再见 | 含有风险字「还」 | 以后咱俩一定再见 |
| 重新写一遍 | 「重」可能误读 | 再写一遍 |
| 转身看向窗边 | 「转」可能误读 | 回头望向窗边 |
| 我看着你的脸 | 「着」可能误读 | 我望向你的脸 |
| 唱得太满 | 「得」可能误读 | 歌声太满 |

### 同音字（最后手段，交付前试听）

```text
原意：你还在我的身边 → 推荐：你依然在我的身边 → 同音标记：你孩在我的身边
原意：把喜欢藏在心里面 → 推荐：把喜欢留在心里面 → 同音标记：把喜欢常在心里面
```

### 重点检查清单（结合语境确认，不局限此名单）

```text
还、长、藏、行、重、转、着、得、差、数、分、看、没、说、过、为、应、只、空、觉、弹、乐、相、和、朝、间、处、角、曲、落
```

## 六、时长与篇幅估算

- 主要段落每段 4-8 行，避免歌词过密导致时长失控。
- 预计时长参考：4/4 拍下每小节约 `60 ÷ BPM × 4` 秒；整曲约 30-50 小节时长为 1.5-3.5 分钟，输出蓝图时给出预计小节数与预计时长。
- 生成后必须试听；发现误读时先改写句子，再考虑同音字替换。
